# Search and visibility setup

## Google Search Console — owner action
1. Open https://search.google.com/search-console/ using the Google account that should own RP Hunt Design.
2. Add a Domain property for rphdesign.com.
3. Copy Google's exact DNS verification record into the domain's DNS settings in GoDaddy. Keep existing website and email records.
4. Return to Search Console and verify. DNS verification may take time to become visible.
5. In Sitemaps, submit https://rphdesign.com/sitemap.xml.
6. Inspect https://rphdesign.com/ and the Projects and Pricing pages. Check the indexed URL, crawl status, and Google-selected canonical; request indexing after verification where appropriate.
7. Review queries, impressions, clicks, and indexed pages regularly. Sitemap submission is not a guarantee of indexing.

Do not put account credentials or private tokens into the repository. If Search Console supplies a public HTML verification file instead, it can be added to both site roots as an alternative verification method for a URL-prefix property.
